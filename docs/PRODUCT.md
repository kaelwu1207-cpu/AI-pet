# AI-pet 产品定位与需求基线

基线日期：2026-10-25。状态：用户方向已确定，产品实现待开发，最终体验待人类验收。

## 目标与使用场景

用户长期在 OLED 屏幕上工作，需要保持软件布局、线框、工具栏或任务栏可见。AI-pet 通过自然的飞行、攀爬、追逐和施法，对这些长期静止区域进行间歇性覆盖、动态替换或调暗；后台记录真实覆盖范围和时长，让活动既有趣味又有可核实的局部减负作用。

用户看见一只调皮宠物，系统根据画面稳定程度、亮度特征、覆盖不足与当前操作位置安排活动。看似随机的行为具有区域覆盖策略和打扰预算。

本产品的作用边界是工作期间的局部动态屏保辅助：保留全屏屏保、系统关屏与面板维护各自的职责。可测量覆盖、调暗和静态暴露指标；烧屏概率下降与面板寿命增益需要独立长期研究，不能由覆盖率直接推出。

## 已确定的产品原则

1. Windows 桌面首发，原生多屏；按屏管理 GPU 帧、静态图和覆盖状态。
2. GPU 桌面帧是像素感知主路径；通过系统图形 API 取得纹理，不依赖周期生成截图文件。
3. 运动、覆盖调度、即时避让在模型不可用时持续工作。
4. 皮肤、动作动画、特效独立定义与替换，通过可校验契约和绑定组合。
5. 优先复用许可和质量可核实的开源能力，允许拼接不同项目的运动、渲染、采集与事件功能。
6. 当前核心交付提供视觉模型、API 汇报和任务监控的稳定扩展接口与测试适配器；实际提供商及真实业务连接按后续功能包接入。
7. 默认本地分析、短时持有画面；视觉上传必须由用户启用的目标、范围与触发策略约束。

## 用户体验

- 工作时宠物从屏幕一侧飞到另一侧，在窗口、任务栏和边缘跳跃，避免机械扫屏。
- 宠物可在合适区域放出烟雾、黑洞、幕布、墨水、粒子或其他魔法，效果有面积、持续时间和强度预算。
- 鼠标靠近、输入或拖拽发生时，宠物和遮挡及时让开；用户可暂停、降低活跃度、划定禁入区或偏好区。
- 用户阅读静止画面时也可能需要专注；无鼠标活动不等于允许遮挡。提供保守默认和随时打断。
- 每屏分别配置开启状态与覆盖积极度。宠物跨屏遵循实际屏幕布局，断开的显示器不继续派发任务。
- 覆盖统计采用易读的区域热图、实际遮挡/调暗时间和观测健康说明，按需查看，不常驻形成新的固定亮区。
- 外部任务的完成、失败、等待输入可转为宠物动作、短暂气泡或未来语音；多事件合并、去重并受安静策略约束。

## 需求与成功标准

| ID | 需求 | 成功标准/验收锚点 |
|---|---|---|
| R01 | 多屏 GPU 帧采集 | 两屏以上独立帧流、时间戳、拓扑变化和采集故障可观测 |
| R02 | 静态区域识别 | 能区分固定线框、动态视频、闪烁光标，采集故障不累计为静态 |
| R03 | 覆盖调度 | 覆盖不足区获得可解释的访问机会；实际覆盖时长影响后续目标选择 |
| R04 | 自然运动 | 飞行/路线/攀爬/跳跃可组合，目标驱动与随机变化并存 |
| R05 | 局部效果 | 能绘制身体以外的特效及不透明纯黑遮罩，工作界面保持可操作 |
| R06 | 操作避让 | 焦点、鼠标、拖拽、菜单与禁入区参与调度；可立即暂停 |
| R07 | 多屏使用 | 混合 DPI、横竖屏、负坐标、HDR/SDR、插拔和休眠恢复有验证记录 |
| R08 | 资源解耦 | 更换皮肤、动作包或特效包时不修改其他两类包与核心调度代码 |
| R09 | 资源安全与降级 | 导入可验证、失败保留上一可用组合；缺动作/模型/特效有确定降级 |
| R10 | 视觉预留 | 同一帧源可按屏/窗口/区域生成受策略约束的视觉请求，测试适配器可端到端验证 |
| R11 | API 汇报预留 | 本机认证事件入口、版本化事件、限流/去重/通知映射可验证 |
| R12 | 任务监控预留 | 支持多任务身份、真实状态、心跳失联与等待输入；不从进程存活推断业务完成 |
| R13 | 性能与隐私 | 采集/分析/渲染/视觉频率分离，资源有上限；默认无持久画面/云上传 |
| R14 | 可复现与发布边界 | 项目独立 Git、Hyper-V 验证回执、许可记录、清理和人工发布门禁明确 |

## 当前交付与扩展分层

核心交付：多屏 GPU 帧感知、静态识别、覆盖与操作避让、宠物运动、可计量的局部效果、三类资源包、设置与统计、本地接口及模拟适配器。

后续扩展：真实视觉模型、持续画面观察、语音、业务系统连接、具体 AI 客户端任务适配器、更多皮肤/骨架/魔法包。扩展必须遵守同一身份、权限和资源预算；当前预留接口完成不表示真实模型或业务服务已接通。

## 产品验收场景

1. 双屏工作：一屏固定编辑器/线框，另一屏视频。宠物优先访问适合活动的静态区，视频区不被误判为整块静止。
2. 任务栏魔法：宠物经过任务栏并局部施法，统计按实际图形记录；鼠标移入可立即操作原图标。
3. 资源交换：同一调度任务依次使用不同皮肤、动作包、效果包；缺失能力显示清晰降级，不崩溃。
4. 连续工作：真实阅读与输入过程中，用户可接受活动频率、遮挡时长和避让体验；人类给出最终体验判断。
5. 多屏变化：插拔、缩放、旋转、休眠恢复后，区域与鼠标坐标仍对齐，过期派发被撤销。
6. 模型/网络不可用：局部动态屏保继续，模型/监控状态按真实原因呈现。

工程阈值在 PLAN 的验收门中量化；产品价值和最终体验由人类验收。

## 回执语义

`CoverageReceipt` 记录实际窗口矩形、单调起点/最后健康观测、时钟频率、观测毫秒、窗口像素毫秒、混合类型/alpha、结束原因、前台保持、撤除确认与工作进程退出码。

开始时间在显示/物理几何核对和DWM提交后取得，后续仅在窗口可见、几何和显示范围仍有效时续记。正常结束先撤窗再核对，父进程在进程退出后独立验证窗口消失。回执缺失或身份不匹配返回 `EvidenceLevel=missing`、零面积/零信用；UI卡死只保留最后健康观测之前的时间，不以计划时长补账。

`WindowPixelMs` 是窗口级观察量。`OcclusionStatus=unknown-external-occlusion` 显式保留其他软件/安全桌面/置顶窗口的遮挡不确定性；当前不把它直接写成面板有效调暗剂量或寿命提升比例。未来 M03 结合自身遮罩、可观测状态和覆盖策略决定信用。

- 单物理屏，5120×2160；原始焦点保持；测试只在自有局部窗口内检查合成内容。

- 系统命中测试跨进程返回下层测试窗口；黑幕WM_NCHITTEST返回透明，NOACTIVATE/TRANSPARENT/LAYERED样式均实际存在。
- 复用 windows-capture WGC 观察到黑幕内部为黑、外围仍为白；只在内存检查自有ROI，不输出图像。此验证桥使用CPU映射，Rust生产纹理路径保持。
- 到时、提前取消、心跳失联、效果UI线程卡死、效果进程被杀而没有回执、宿主被强杀造成管道断开、宿主正常异常展开均有撤除测试。
- 构建启用警告作为错误；定向请求拓扑/范围错误在运动前拒绝。测试不操纵用户鼠标或键盘。

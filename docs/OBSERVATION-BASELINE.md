# 静态识别冻结基线与全屏资源预算

日期：2026-10-25。归属M01/M02/M03/M10，当前参数定义为 `contracts/static-v1.json`，短时参考资源门禁为 `contracts/performance-v1.json`。Rust编译包含与宿主嵌入资源读取同一识别定义；文件指纹进入每次运行回执。定义改变时更新版本、夹具正确性与性能证据。

## 冻结口径

| 参数 | 值与语义 |
|---|---|
| 比较域 | WGC RGBA8，GPU转RGB24；逐次有效观测比较 |
| 色差 | 任一通道差大于7/255才重新计时，7保留、8重置 |
| 稳定阈值 | 500ms有效连续观测；GPU像素历史计数上限3600000ms |
| 边缘 | max(R,G,B)>0.15，右/下邻居最大通道差>0.2 |
| 区域候选 | 64×64；有稳定亮边缘，或稳定像素比例≥0.95且亮度特征≥0.05 |
| 时长特征 | StableMs描述受关注稳定内容的已观测时长，不能解释为整块区域每个像素都静止 |
| 更新/过期 | 上游最小更新间隔120ms；600ms无新鲜统计暂停覆盖；超过1000ms源间隔重建历史 |
| 输出 | 生产候选按64×64在GPU聚合，16×16保留为精细诊断；逐像素历史和阈值一致 |
| 资源边界 | 单消费者最多16777216像素，自有纹理/缓冲预算256MiB，最多16个自身遮罩 |

变化的像素独立重新计时；闪烁光标不清除邻居的稳定边缘。遮挡像素标不可观测，宿主保留先前事实，遮挡期间不增加底层时长；揭露后重新建立连续性。曝光统计是离散采样所得，采样间隙中的变化与低于阈值的慢变化仍存在观测边界。

## 冻结夹具和真值

GPU直接输入夹具由 `src/capture-rust/src/gpu_tests.rs` 定义，自有64×64纹理上传后只读回计数；16px与64px输出执行同一组真值：499/500ms、7/8色差、亮度/对比边界、固定1像素线、单像素闪烁、自遮挡、揭露重建、计数上限及17×17非整块ROI。

真实桌面夹具由JSON的Fixture部分和 `tests/pet-hosts/LoopGpu.cs` 的无边框WPF绘制共同定义。320×128自有场景包含1物理像素白线、180ms闪烁光标和70ms变化色块，测试窗口和捕获须位于同一交互桌面。回执同时记录配置与代码指纹；改变绘制或时间定义时重新验证像素真值。

## 全屏统计、调度和计量

原始WGC纹理只在上游回调租约内使用，复制ROI至自有GPU纹理。D3D11计算着色器输出可见/稳定/稳定亮边缘/变化/掩蔽数量、最大时长和亮度总和。GPU时间戳范围覆盖ROI复制与计算，分析墙钟另包含等待和计数构建；JSON编码、管道、宿主解析由进程CPU及端到端间隔体现。

5120×2160对应2720个64px区域，每帧读回87040字节计数；逐像素图像没有CPU读回。16px诊断输出为1382400字节，属于同一阈值下的输出粒度对照。实际IPC另含JSON字段和元数据，不等于二进制计数大小。

调度首先排除不可观测及操作禁入区域，优先选择实际窗口服务毫秒最少的候选，固定种子打散平手。全屏网格用等长实测格式回执重放公平性；真实闭环另限制TargetBounds在自有场景内，驱动VPet和实际局部黑幕，避免测试时在工作内容上随机施放效果。

## 资源验收与证据

参考机：单块5120×2160活动屏，RTX5090、32逻辑处理器。门禁基于初次16px/64px实测冻结：分析p95≤25ms、GPU指令时间p95≤5ms、宿主聚合p95≤10ms、选择p95≤5ms、源间隔p95≤250ms；采集/宿主CPU分别≤整机2%/3%，各内存与统计预算见机器定义。每轮预热1秒、测量6秒，至少35个快照且无过期。

`tools/loop/performance.ps1` 使用C# Release与Rust release执行三轮，并运行相同的GPU真值测试。CPU原始数值为单核等效百分比，除以32才是参考机整机份额；工作集、私有内存、DXGI本进程local/nonlocal用量和自有资源字节分别记录。DXGI用量包含驱动/WGC所有权与驻留差异，不用其倒推每张纹理的实际显存。

原始结果归data/receipts/performance，控制记录含源码检查点、配置/源码/程序指纹、退出码、超时及每项预算结果。短时结果不证明8小时无泄漏，不表示其他硬件或多屏功耗验收。开发优化对照使用Rust debug；正式参考预算结果单列Rust release，禁止混合编译模式计算加速比。

# GPU静态观察与覆盖调度闭环

日期：2026-10-25。归属 M01/M02/M03/M04/M05/M09/M10。当前实现复用 windows-capture 的 WGC/Rust 原始纹理与 VPet Core 的运动/显示接口；新增产品独有的静止历史、遮挡状态、公平服务和操作仲裁。自有WGC对照后端保持原用途。

## 数据与执行路径

`windows-capture Frame` → GPU裁剪ROI → D3D11逐像素比较/时长 → GPU 64×64统计（16px诊断）→ 区域候选 → 最少已观测服务时长/随机平手选择 → VPet定向移动 → 独立局部黑幕 → 实际回执去重/校验 → 当前epoch服务账本 → 下一目标。

GPU持有RGB24历史与毫秒计数，当前历史计数上限1小时，仅向CPU读回每细分块32字节计数。1像素亮边缘单独累计，不被整块平均颜色抹掉；局部闪烁只重置变化像素。`StableMs` 是块内受关注稳定内容的时长特征，不代表整个64×64区域所有像素均静止。原始统计同时保留可见/稳定像素、稳定亮边缘、变化像素和亮度总和。

自身身体采用实际窗口矩形及保守外扩遮罩，移动前预约整个扫过路径并等待GPU代次确认，以覆盖采集与窗口位置的时间差；到位后再确认实际身体遮罩。效果区域在启动前等待GPU遮罩代次确认。遮挡时底层标为不可观测，宿主保留此前事实，隐藏期间不增加时长；揭露像素重新建立连续性。源间隔超过1000ms重置GPU连续历史，600ms没有新快照或进程退出时停止派发/取消活动计划。捕获尺寸/格式变化会终止统计流，等待新拓扑代次重建。

## 覆盖和公平性

候选要求当前可观测、稳定内容时长≥500ms，并有稳定亮边缘或足够亮度。首先选择实际窗口服务毫秒最少的可用区域，固定种子打散平手；暂时禁入/不可观测区域不参加当次选择，失败重试有短退避。

回执按planId去重，核验版本、显示身份/epoch、单调时钟、时长与面积的一致性。缺失证据、无撤除确认及不符合黑幕口径的回执不增加服务量。局部相交按实际交集面积折算。公平性账本是已观测窗口服务量，外部遮挡未知仍保留，不能当作已校准的OLED有效调暗剂量。

## 操作避让

默认原生来源只读鼠标坐标、最近系统输入时间和可用caret矩形，不读取正文。鼠标周围80px、caret周围24px形成空间禁入；最近300ms有系统输入则暂停派发。目标和保守扫过路径都要检查；运动/黑幕期间约每20ms复查，命中禁入或源过期即取消。现阶段采用保守直线路径包围矩形，复杂绕行留给后续运动适配。

测试回放将“系统其他区域近期活动”位设为受控值，并保留实际鼠标/caret空间禁入；通过注入策略区域验证中途撤除，不注入系统键鼠事件。纯逻辑测试单独验证近期输入的全局暂停。外部CLI继续使用完整原生策略，其暂停/取消属于可核对的运行结果，不强行记为已覆盖。

统计流支持指定设备身份、负桌面坐标、最多16777216像素ROI、16个自身遮罩，默认15秒且配置限1—30秒；每个闭环阶段限1—12秒、最多8次动作，恢复协调器总请求限1—30秒/3次尝试。真实全屏5120×2160按64px输出每帧读回87040字节计数；320×128诊断夹具按16px输出5120字节。统计链未读回图像像素，JSON另有元数据开销。原宿主回归使用Python CPU探针检查自有黑幕，所有阶段均不保存屏幕图像。

# 模块接口契约 v0.1

日期：2026-10-25。本文是语义规格；尚未生成可执行 schema、SDK 或服务。首个接口工作包将其固化为 `contracts/` 下机器可校验定义，并提供有效、无效、跨版本夹具。

## 公共信封与兼容

所有跨模块消息带 `schemaVersion`、`messageId`、`sourceModule`、`correlationId`、`createdAtUtc`、`monotonicTime`、`runId`；按消息类型带 `displayId`、`topologyEpoch`、`frameId`、`planId`、`assetGeneration`。时间单位、坐标与色彩域在 schema 明确，不接受隐式猜测。

主版本不兼容拒绝并报告原因；次版本允许约定的可选字段；未知枚举有显式 unknown/fallback。无效消息不修改权威状态；请求支持 deadline、取消和幂等 ID。分模块/分显示器背压，有界队列，过期任务撤销，优先保最新有效状态。

规范身份与校验状态使用稳定 ID/枚举。宠物昵称、显示器别名、翻译、气泡措辞仅为展示字段，不用作去重、完成判定或进度权威。

## 核心数据契约

| 契约 | 必需语义 | 权威写入者 |
|---|---|---|
| `DisplayTopology` | 稳定显示身份、临时系统句柄映射、适配器、物理桌面矩形、像素尺寸、DPI/旋转、色彩与连接状态、epoch | M01，宿主提供偏好 |
| `FrameLease` | 显示/帧 ID、epoch、时间戳、尺寸、格式/色彩域、后端、可信状态、租约/释放与同步规则 | M01 |
| `CaptureHealth` | initializing/healthy/no_new_content/degraded/unavailable/stopped，最近有效时间、错误、恢复代次 | M01 |
| `ObservationTile` | 物理区域、多尺度索引、采样跨度、稳定比例/时长、亮度与边缘特征、置信度、可观测遮罩、关联健康 | M02 |
| `InteractionContext` | 鼠标位置、焦点区域、输入/拖拽/菜单状态、用户禁入/偏好区、有效期；不包含键入正文 | M09，可选系统辅助适配器 |
| `CoverageLedger` | 按物理区域/时间窗的访问、实际替换、调暗等效、额外亮效、未知观测；保留统计口径版本 | M03 |
| `ActionPlan` | 目标显示/区域、路线/行为、资源能力要求、预计覆盖、强度/持续预算、优先级、可取消条件、截止时间 | M03 |
| `MotionState` | 实际位置/速度/姿态/运动模式、动作阶段与锚点、身体覆盖输出 | M04 |
| `EffectRequest` | 目标区域/锚点、效果语义、参数、预算、持续与取消策略、所需纹理范围 | M03 统一仲裁后派发 |
| `RenderCoverageReceipt` | 实际渲染开始/结束、显示与帧代次、形状或有界 alpha 栅格、替换/混合/加色类型、调暗估计、裁剪/遮挡/未知、资源代次 | M04/M05 各自提供；M03 汇总 |
| `AssetSetResolved` | skin/motion/effect/binding 的 ID/版本/摘要/许可引用、能力集合、降级映射与 generation | M06 |
| `VisionRequest` | 目标显示/窗口/ROI、触发来源、帧新鲜度、是否允许多帧、模型能力/策略、超时、上传范围 | M07 依据策略构建 |
| `VisionResult` | 请求与输入帧引用、来源模型、结构化解释、置信/未知、错误、实际耗时；不携带执行授权 | M07 |
| `IntegrationEvent` | provider/project/session/task/run、eventId/sequence、类型/严重度、结构化 payload、来源时间与认证主体 | M08 验证后规范化 |
| `TaskState` | queued/running/waiting_input/succeeded/failed/cancelled/unknown；独立 freshness、最后心跳、状态来源 | M08 |
| `RuntimePolicy` | 每屏开关、打扰预算、采样/内存/效果预算、隐私、资源包选择、凭据引用与策略版本 | M09 |
| `EvidenceReceipt` | 项目/运行/nonce/VM/检查点/输入指纹、真实退出码/超时/异常、指标、清理与门禁覆盖 | M10 汇总，原始结果由实际执行层出具 |

`FrameLease` 的 GPU 句柄仅在后端协商与安全 IPC 规则内使用。消费者必须主动归还；跨进程复制或共享会显式记录设备匹配、同步和成本。若帧过期/epoch 改变，消费者拒绝继续解释旧坐标。

## 坐标与时间

- 捕获与覆盖统计的基准为显示器物理像素；桌面物理坐标允许负值。
- 引擎逻辑坐标、UI DIP 和图像像素通过带 epoch 的变换显式转换。
- 每个区域同时带 displayId 与 coordinateSpace；单独的 x/y 不构成有效位置。
- 帧以单调时间计算间隔，UTC 用于人类记录；各屏异步，拼接视觉输入标注时间偏差和过期屏。
- 不存在显示器之间的空白桌面区域不计覆盖；跨屏路径明确跳转/退场/再入策略。

## 接口矩阵与写权限

下表列出全部允许的模块间边；未列出的直接写入与隐式读取均不允许。所有模块可读取 M09 提供的相关策略只读视图；M10 可读取脱敏指标/回执，不反写业务事实。

| 接口 ID | 方向 | 允许读取/事件 | 缺失/失败行为 | 禁止耦合 |
|---|---|---|---|---|
| I01 | M09→M01 | 启停/预算，M01→订阅者发布拓扑/健康 | 显示不可用，撤销相关计划 | 用用户别名代替显示身份 |
| I02 | M01→M02 | FrameLease、拓扑、健康 | 标记不可观测，停止错误累积 | 捕获异常当长期静态 |
| I03 | M02→M03 | ObservationTile 增量/快照 | 保守巡游或暂停定向覆盖，标注原因 | 直接读/改观察内部纹理 |
| I04 | M09→M03/M04/M05 | InteractionContext、暂停、策略版本 | 状态过期采用低打扰退避 | 记录键入正文推测意图 |
| I05 | M03→M04 | ActionPlan、取消/替代 | 拒绝不支持动作并回报 | 皮肤资源直接移动窗口 |
| I06 | M03→M05 | EffectRequest、取消/预算 | 使用安全基础效果或跳过 | 模型/效果绕过调度施法 |
| I07 | M04→M05 | 同 planId 的锚点与动作阶段事件 | 锚点失效撤销跟随效果 | 效果反向篡改宠物物理状态 |
| I08 | M04/M05→M03 | 实际状态、RenderCoverageReceipt | 缺回执不记为已覆盖，超时撤除 | 预计范围替代实际覆盖 |
| I09 | M06→M04/M05 | AssetSetResolved、不可变资源句柄 | 保留上次可用组合/基础资源 | 动画和特效直接读皮肤私有文件 |
| I10 | M01→M07 | 受策略限定的 FrameLease/目标映射 | 返回 unavailable/stale，取消请求 | 视觉长期占有采集纹理 |
| I11 | M07→M08/M09 | VisionResult、进度/错误 | 确定性提示模型不可用 | 模型修改静态事实/任务成功 |
| I12 | 外部→M08→M03 | IntegrationEvent→规范通知意图 | 无认证/超限拒绝，来源失联标 unknown | 任意 Shell 或输入注入 |
| I13 | M09→M06 | 包导入/切换请求、策略 | 原子失败，上一组合继续 | 导入包自启动脚本 |
| I14 | M03/M09→M07 | 按需视觉请求与取消 | 保持核心运动/覆盖可用 | 每个渲染帧都调用模型 |
| I15 | M01—M09→M10 | 脱敏健康、指标、门禁结果 | 证据缺失则门禁待验证 | 日志或 UI 文本代替真实退出码 |
| I16 | M04/M05→M02 | 实际身体/效果遮罩及代次，只读用于底层可观测性 | 自身区域无法确定时保守标 unknown | 自身动画直接清零静态时间 |

## 模型、API 与任务接口边界

视觉提供商声明 text/image/multi_image/video 等能力；API Key 保存为宿主凭据引用。第一版 schema 和模拟适配器验收不要求真实云账号。云端上传必须匹配 RuntimePolicy 的目标、触发与范围；默认不上传。

本机事件入口仅绑定回环接口或使用本机受控 IPC，提供可供独立客户端使用的凭据发现/配置机制；不依赖服务进程临时环境变量自动传播。认证、最大消息、限流、重放/乱序/重复和任务隔离均需测试。

TaskState 依据来源事件或正式状态查询变更；心跳失联仅更新 freshness/unknown，不制造完成。通知意图统一进入 M03 仲裁，动作异常可取消；外部内容按纯文本或受限格式展示。

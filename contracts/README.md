# AI-pet 机器契约与冻结基线

本目录归AI-pet，维护源码内可校验的模块配置/消息定义；与docs/CONTRACTS语义规格配套，随Git保留，变更时同步消费者与验收。

`static-v1.json` 是静态识别首版冻结参数及自有桌面夹具定义，由Rust编译包含和宿主嵌入资源共同读取。修改参数或夹具须更新基线版本、正确性和性能证据；运行回执保存文件指纹。它是SDR/8bit比较域的工程基线，阈值不表示面板材料老化剂量。测试的GPU合成输入由程序生成，实际屏幕像素保持瞬时。

`performance-v1.json` 是5120×2160/RTX5090/32逻辑处理器参考机的首版短时资源门禁，基于细分块与64px聚合实测冻结；不外推其他硬件、HDR或长期功耗。按帧读取计数，GPU时间仅覆盖纹理复制与计算指令，CPU/内存指标包含测试进程的宿主和小型夹具。其他硬件先生成同口径结果再建立相应预算。

# 常驻宿主控制与测量

`run.ps1` 使用私有 .NET 与已构建的 `data/build/resident/AIpet.Host.dll`、Rust release observe；启动真实托盘宿主，默认10分钟，最大8小时。`-ExercisePause` 在10秒暂停、13秒恢复；时限到达通过宿主退出接口收尾。所有输入、统计、进程码与源码指纹写入 data/receipts/resident。仅本地统计，不持久化屏幕像素。

脚本由 AI-pet 维护；每次运行独立 runId/nonce，测试时源码冻结。超过10秒退出预算记录强制终止，不把强杀视为通过。CPU 汇总包含宿主、所有完成的采集代次、独立黑幕进程；内存/句柄为1秒采样峰值，启动瞬态可能更高。已有统计基线不替代全宿主结果。回执至少保留至模块集中审核关闭。

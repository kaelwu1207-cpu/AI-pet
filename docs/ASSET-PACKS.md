# 皮肤、动作动画、局部特效与绑定规范 v0.1

日期：2026-10-25。本文定义解耦目标与包语义，机器 schema、编辑器和样例资源待开发。

## 1. 独立替换的四类对象

| 类型 | 负责内容 | 输出能力 | 依赖边界 |
|---|---|---|---|
| `SkinPack` 皮肤包 | 外观贴图/模型/材质、骨架或帧图集、尺寸、命中形状、视觉覆盖形状、锚点 | rigProfile、渲染能力、可用身体部件/帧角色 | 不写路线、覆盖优先级或外部服务配置 |
| `MotionPack` 动作包 | 语义动作、局部姿态/时间线、帧角色选择、动作事件、可混合/中断窗口 | idle/walk/fly/climb/jump/cast/react 等动作 | 通过 rigProfile/绑定访问外观；不直接操纵系统窗口/业务状态 |
| `EffectPack` 特效包 | 粒子、着色器、序列帧、遮罩、音效引用、参数/生命周期与覆盖核算配置 | smoke/blackout/ink/portal/trail 等效果 | 接收区域或命名锚点，不硬编码特定宠物文件/绝对屏幕坐标 |
| `BindingProfile` 绑定配置 | 将动画语义、骨骼/帧角色、锚点及效果触发映射到具体组合 | 兼容匹配、能力与降级表 | 仅做声明式映射，不承担运动算法和调度 |

渲染适配器属于程序模块，可支持 sprite/procedural/Live2D 等后端。每个可执行适配器由可信程序安装/发布流程管理，资源包不得携带任意原生库或可执行脚本。

“可独立替换”表示满足同一契约的组合无需改核心代码。骨架、朝向或动画资产不同可以需要独立绑定。精灵帧属于外观表现数据，动作包按语义选择帧角色与时间；跨精灵与骨架渲染的差异由适配器承担。

## 2. 包布局与清单

拟定包目录：`manifest.json`、对应类型的声明配置、`resources/`、`LICENSES/` 和可选 `previews/`。分发内置包放 `assets/`；用户包、导入暂存和回滚副本位于开发/日用数据根对应资源角色，实施前在数据 README 登记具体路径和保留规则。

公共清单字段：`schemaVersion`、`packId`、`packVersion`、`packType`、`displayName`、`author`、`licenseRefs`、`sourceRefs`、文件摘要/大小、兼容引擎/适配器、依赖的能力/包版本范围、资源预算与入口声明。

包 ID 与版本为身份；显示名和预览可变。资源引用只能是包内经过规范化的相对路径或受控依赖 ID，禁止路径穿越、绝对路径逃逸、符号链接逃逸与网络自动拉取。导入同时限制压缩包展开大小、数量、贴图尺寸、显存预算和特效复杂度。

## 3. 皮肤与动画接口

皮肤声明坐标单位、默认视觉尺寸、朝向、pivot、命名锚点（body/feet/head/cast_origin 等）、视觉覆盖形状与独立命中形状。视觉覆盖不能直接用点击圆形或整个透明窗口代替。

动作输入为 `animationSemantic`、方向、速度/阶段、情绪与归一化时间；输出姿态、帧选择、锚点变换与阶段事件，例如 `cast.begin`、`cast.emit`、`cast.end`。位置由 M04 统一控制；动画中的根位移只能作为建议，经控制器处理。

动作须声明循环、中断条件、过渡时长、必要锚点/骨骼、兼容 rigProfile 与替代动作。避免将动作名称绑定某个角色昵称。缺 fly 外观可使用 idle 姿态配合运动；缺 cast 可使用 react/idle 与通用锚点，降级说明进入诊断。

## 4. 特效接口与覆盖计量

效果输入为目标 displayId/epoch、局部区域或锚点、seed、强度、时长/面积/粒子预算、配色参数和可选受控桌面纹理。不同皮肤可触发同一个效果；同一动作可通过绑定切换效果。

每个效果声明：

- `blendMode` 与适用色彩域：alpha/opaque/additive 等。
- 覆盖类型：实际替换、调暗、额外亮效或 unknown。
- 覆盖输出方式：解析形状、alpha 栅格、离线校验的有界近似；保守口径及误差。
- 持续时间上限、最大区域、预算超限降级、取消/超时撤除行为。
- 是否需要桌面纹理、是否发出声音以及可独立关闭的视觉/声音设置。

实际运行输出 RenderCoverageReceipt；裁剪、被其他窗口遮挡、最小化或未绘制时不得按预计范围计覆盖。真黑效果需验证最终显示为不透明黑色，且鼠标仍按策略穿透。加色光点不自动贡献调暗。

## 5. 原子加载与安全降级

导入 → 结构/路径/摘要/许可和预算检查 → 能力/版本匹配 → 试加载 → 生成完整 AssetSetResolved → 在安全动作边界原子切换。任何一步失败保留上一可用组合；旧资源在 GPU/动画消费者释放后回收。

绑定不满足时选择：明确拒绝不兼容组合，或按声明降级到内置基础动作/效果；不隐式读取其他包私有资源。旧组合回滚副本保留至新组合验收与引用释放完成，随后按登记事件清理。

## 6. 必须通过的组合验收

| 测试 | 验收要求 |
|---|---|
| 同 rig 换皮肤 | 原动作与效果包保持字节摘要不变，表现与计量正确 |
| 同皮肤换动作 | 路线/调度不变，动作时序与 cast 事件正确 |
| 同皮肤/动作换特效 | 特效从烟雾变黑幕，覆盖记录口径随 blend/形状变化 |
| 跨 rig 或渲染适配器 | 经显式绑定可运行；不兼容时明确拒绝或降级 |
| 动作/锚点缺失 | 安全替代，任务结束可回 idle，遮罩按时撤除 |
| 无效/恶意包 | 路径逃逸、超大资源、循环依赖、未知执行入口被拒绝 |
| 运行中切换 | 不残留旧魔法，不访问已释放资源，不丢弃已有覆盖账本 |
| 暂停/错误/设备重建 | 效果可撤除，恢复后重新解析资源代次与显示坐标 |

首个样例组合至少提供两个同契约皮肤、两个动作包和两个特效包，并完成替换矩阵；样例数量仅用于证明解耦，不代表最终内容量。
